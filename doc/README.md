# TraceX Documentation

The documentation is organized by purpose rather than by implementation module.

## Product Foundation

- `vision.md` - long-term product direction and principles
- `01-Product-Requirements.md` - problem and product opportunity
- `02-System-Architecture.md` - target system boundaries and dependency rules

## AI Contribution Controls

- `AI_ENGINEERING_RULES.md` - mandatory behavior for coding agents
- `AI_REVIEW_CHECKLIST.md` - final quality gate
- `prompts/` - reusable task-specific working prompts

## Engineering Handbook

The focused standards under `engineering/` explain how the architecture is
implemented and reviewed. Start with `engineering/README.md`.

## Decision History

Material architectural decisions are recorded in the repository-root
`DECISIONS.md`.
