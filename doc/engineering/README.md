# TraceX Engineering Handbook

This handbook turns the system architecture into day-to-day engineering rules.
Each chapter is intentionally focused so humans and AI agents can load only the
standards relevant to a task.

## Reading Guide

All contributors should read:

1. `01-Rust-Standards.md`
2. `02-Project-Structure.md`
3. The task-specific chapters
4. `07-Code-Review.md` before completion
